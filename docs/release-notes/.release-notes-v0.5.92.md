# v0.5.92

## Overview

This release improves search recall, ranking, result selection and presentation, and upgrades the native ONNX runtime and MCP SDK.

**Full Changelog**: https://github.com/catlog22/maestro-flow/compare/v0.5.91...v0.5.92

## Highlights

- Improve lexical recall and coverage, generalized query and family identity, bounded CJK singleton recall, and separated version-identifier relevance.
- Apply KG eligibility before candidate limits and retain local coverage alongside linked repository results.
- Make search results more compact, actionable and safe, with improved selection behavior.
- Document final query and provider contracts in the English and Chinese search guides.
- Upgrade `@modelcontextprotocol/sdk` to `^1.32.1` and align the root and vendored Transformers `onnxruntime-node` dependency on `1.30.0`.
- Add an offline synthetic ONNX fixture and real native CPU / vendored Transformers tests covering exact inference, tokenization, pooling, normalization and disposal. The fixture tests compatibility, not pretrained model quality.
